## 五、出「壳」并交回给我

「壳」= 编译产物打包成一个 ipa，**里面只有可执行文件与 Info.plist，没有游戏内容**。

```bash
cd d2r-mobile/work/ios

# 用 Release 配置出一个干净的产物
xcodebuild -project DmGame.xcodeproj -scheme DmGame \
           -sdk iphoneos -configuration Release \
           -derivedDataPath ./build \
           CODE_SIGNING_ALLOWED=NO \
           build
```

产物在 `./build/Build/Products/Release-iphoneos/DmGame.app`。

打壳：

```bash
cd ./build/Build/Products/Release-iphoneos
mkdir -p Payload
cp -R DmGame.app Payload/
zip -qry DmGame-shell.ipa Payload
ls -lh DmGame-shell.ipa
```

**把这个 `DmGame-shell.ipa` 发回给我就行**（大约 3~6 MB）。

## 六、可能遇到的问题

| 现象 | 原因与处理 |
|---|---|
| `xcodegen: command not found` | 没装好：`brew install xcodegen`；或 `brew` 不在 PATH |
| `error: Unable to find a destination` | 没连真机也没选模拟器。把 `-sdk iphoneos` 去掉并加 `-destination 'generic/platform=iOS'` |
| 某个 `../host/*.c` 找不到 | `project.yml` 的源文件清单与实际目录不符 —— 把 `work/` 的完整目录树发我 |
| `Use of undeclared identifier` 一堆 | 多半是 `project.yml` 漏了某个 `../host/*.c`。**最少见的才是逻辑错** —— 先对清单 |
| 链接报 `_dm_thread_returned` 未定义 | 那是 `hle_nn_thread.c` 里提供的（aarch64 分支）。确认它被列进 `project.yml` |
| 链接报 `_gate_dispatch` / `_unimpl_c` 未定义 | 见下节的「还没写的东西」 |
| `MTLPixelFormat` 之类未定义 | `hle_nvn_fmt.c` 不依赖 Apple 头（它只返回整数）；若报错说明有别的问题 |
| 汇编报错在 `dm_guest_entry.S` | 确认 target 的 `ARCHS` 是 `arm64` |
